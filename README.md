# Nabd — نبض

Arabic-first website for a fictional gym in Jeddah: class booking, membership plans and a free first session.

**Live demo:** https://sarmadax.com/work/nabd/

## Features
- Live heart-rate hero animation and counting stats
- Class schedule by day and workout type, with seat booking
- Three membership plans in SAR with a monthly/annual switch
- Free trial session form (demo only, no data is sent)

## Stack
HTML5, CSS, vanilla JavaScript, GSAP + ScrollTrigger, inline SVG

## Run locally
No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
